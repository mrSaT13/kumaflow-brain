# ESP-колонка KumaFlow — S3-Zero + PCM5100A + PAM8403

Легкий плеер-клиент мозга: очередь даёт `POST /api/wave/continue`,
звук ESP тянет сам с Navidrome по Subsonic `stream.view`,
позицию публикует в `/api/wave/publish`. Мозг звук не стримит.

Прошивка: `esp_kitchen.ino` (Arduino IDE, ядро esp32 3.x).
Первый прогон — на голой S3 с `DEBUG_NO_AUDIO true` (только логи),
звук включается позже заменой на `false`.

## 1. Что за что отвечает

```
[S3-Zero] --I2S--> [PCM5100A ЦАП] --line L/G--> [PAM8403] --> динамик 4 Ом
   WiFi               3.5мм выход              5В, 2x3Вт        от Яндекс Лайт
```

- **S3-Zero** — мозги и сеть. HTTPS к Brain/Navidrome через KeenDNS.
- **PCM5100A (WeAct)** — I2S ЦАП, делает аналоговый стерео line-out.
  Напрямую динамик НЕ тянет — будет еле слышно. Ему нужен усилитель.
- **PAM8403 (мини-плата GigaVolt)** — усилитель D-класса. Один канал
  на динамик. Без крутилки громкости — громкость только софтом.
- **INMP441** (если есть) — это МИКРОФОН, для воспроизведения не нужен.
  Пригодится позже для фичи «Сонар» (узнать что играет).

## 2. Пайка: S3-Zero <-> PCM5100A (I2S)

| PCM5100A | S3-Zero | Комментарий |
|---|---|---|
| VCC | 3V3 | Только 3.3В! Не 5В |
| GND | GND | общий |
| BCK (BCLK) | GPIO7 | бит-клок |
| DIN (DATA) | GPIO9 | данные |
| LRCK (WS/LCK) | GPIO8 | выбор канала |
| SCK | GND | **обязательно на землю** — включает внутренний PLL, иначе молчит |
| FLT / FMT / DEMP (если есть) | GND | штатный режим |

В скетче это: `audio.setPinout(8 /*LRCK*/, 7 /*BCLK*/, 9 /*DIN*/)`.

```
PCM5100A         S3-Zero
┌──────┐         ┌───────┐
│ VCC  ├─────────┤ 3V3   │
│ GND  ├─────────┤ GND   │
│ BCK  ├─────────┤ G7    │
│ DIN  ├─────────┤ G9    │
│ LRCK ├─────────┤ G8    │
│ SCK  ├────┬────┤ GND   │
└──────┘    │    └───────┘
            └─ перемычка SCK-GND
```

## 3. Пайка: PCM5100A <-> PAM8403 <-> динамик

У мини-PAM8403 одна сторона — вход, другая — выход.
Маркировка на шелкографии: `5V / R / GND-вх / L` и `OUT R± / OUT L±`.

| Откуда | Куда | Комментарий |
|---|---|---|
| PCM5100A 3.5мм TIP (левый) | PAM `L` | отрезать джек, припаять жилу |
| PCM5100A 3.5мм GND | PAM `GND` входа | земля линии |
| PCM5100A правый (R) | — | не подключаем, колонка моно |
| PAM `5V` | БП 5В / 1А+ | **отдельный БП, не от USB ESP** |
| PAM `GND` питания | GND общий с ESP | земли объединить обязательно! |
| PAM `L+ / L-` | динамик +/- | только один канал |
| PAM `R+ / R-` | — | оставить висеть, НЕ замыкать |

```
PCM5100A (джек)     PAM8403            Динамик Лайт
  TIP (L) ─────────► L
  GND ─────────────► GND-вх
                     5V ◄────── 5В/1А+ (отдельно)
                     GND ◄───── GND общий с ESP
                     L+ ─────────────────► (+) динамика
                     L- ─────────────────► (-) динамика
                     R+, R- — пусто
```

Нюансы именно этой платы:

1. Без регулятора — стартовая громкость в скетче `audio.setVolume(5)`
   из 21. С 21 не стартовать!
2. Питание от USB ESP даст свист/хрип — только отдельный 5В.
   Конденсатор 470–1000 мкФ по питанию прямо на плату сильно помогает.
3. Не включать без подключённого динамика.

## 4. Питание итого

- ESP S3-Zero — от USB (комп / зарядник).
- PCM5100A — от 3V3 ESP (потребление маленькое).
- PAM8403 — от отдельных 5В/1А+.
- Все GND общие. Без этого — фон и хрип.

## 5. Прошивка (Arduino IDE)

1. Boards Manager → `esp32 by Espressif 3.x` → установить.
2. Плата `ESP32S3 Dev Module`, в Tools:
   `USB CDC On Boot: Enabled`, `USB Mode: HW CDC and JTAG`,
   `PSRAM: OPI PSRAM`, `Flash Size: 4M`.
3. Библиотеки: `ESP32-audioI2S` (schreibfaul1),
   `ArduinoJson` (Benoit Blanchon, v7).
4. Открыть `esp/esp_kitchen.ino`, заполнить верх:
   `WIFI_SSID/PASS`, `BRAIN_URL` (https KeenDNS без слэша),
   `BRAIN_TOKEN` (Настройки → Токены, скоуп wave, или `""`),
   `USER_ID` (uuid юзера мозга), `NAVI_URL` (https KeenDNS музыки),
   `NAVI_USER/NAVI_PASS`.
5. Оставить `#define DEBUG_NO_AUDIO true`, залить, открыть
   Serial Monitor 115200. Если порт не шьётся: зажать BOOT,
   ткнуть RESET, отпустить BOOT, прошить.
6. Ожидаемый лог: `WiFi OK` → `POST /api/wave/continue -> 200` →
   `+ Артист - Трек [id]` → `publish heartbeat ok`.
   В вебе `/wave` появится слот `esp_kitchen`.
7. После успеха: `DEBUG_NO_AUDIO false`, залить снова —
   появится звук. Громкость наращивать с 5 вверх.

## 6. Почему по домену, а не по IP

Раньше советовали LAN-IP, но раз моб/десктоп уже ходят через
KeenDNS по HTTPS — ESP ходит так же. Важно: для TLS нужны
правильные время (в скетче есть NTP: `pool.ntp.org`) и
`setInsecure()` (уже в коде — домашний LetsEncrypt принимаем
без проверки CA, в доверенной сети ок).

## 7. Не работает — смотри сюда

- `WiFi FAIL` — неверные SSID/pass или сеть 5 ГГц (нужна 2.4).
- `401` от Brain — неверный `BRAIN_TOKEN` или не тот скоуп.
  Без токенов в БД — auth выключен, ставь `""`.
- `wave пустая` — неверный `USER_ID` или в библиотеке нет
  проанализированных треков.
- Тишина при `DEBUG_NO_AUDIO false`, но логи идут —
  проверь `SCK→GND` на PCM5100A (топ-1 причина),
  пины 7/8/9, питание PAM 5В, общий GND.
- Хрип/свист — PAM запитан от USB ESP. Дай отдельные 5В.
- Орет — `setVolume(5)` для начала, у платы нет крутилки.
