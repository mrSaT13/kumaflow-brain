## Что сделано в мозге (0.3.35 → 0.3.37)

**Проблема, с которой начали:** голос/ASR пишет «Эминем» кириллицей, в каталоге
«Eminem» — обычный поиск не находит.

- **0.3.35 — спасатель запроса.** `POST /api/resolve/query`: точное совпадение →
  транслитерация → «звуковой» ключ (гласные убраны) → похожесть написания →
  совпадение по слову → выученные алиасы. Плюс внешний кандидат из Яндекс.Музыки.
  Самообучение без тыков: `query_misses` (промахи) + `query_aliases` (память);
  мозг сам разбирает промахи (`auto_learn`) и учится на поведении юзера
  (`learn_from_behavior`). Крон «Самообучение поиска» раз в час.
- **0.3.36 — склейка похожих написаний.** Голос пишет одно слово по-разному
  («имейджен драгонс» / «имайджен драгонс»): ближайшее похожее написание
  алиаса теперь тоже срабатывает.
- **0.3.37 — треки/альбомы + ИИ.** Резолвер по видам `artist|track|album|any`;
  запрос «Eminem Lose Yourself» ищется по паре «название + исполнитель».
  `services/query_ai.py`: модель получает список названий из библиотеки и
  предлагает варианты (id не выдумываются); предложения копятся в
  `ai_suggestions` и ждут решения юзера — «Это оно» (→ алиас) / «Не то».

### Веб-морда

Страница **/resolve** («Умный поиск» в меню «Задачи»): плитки статистики,
таблица выученного (правка/забыть), список промахов (кнопка «Научить»),
форма «Научить слову», проба «Что поймёт мозг», массовый импорт/экспорт
текстом (`слово = как правильно`), раздел **«Предложения ИИ»**.
Проба ищет по всем видам (`kind: any`) и показывает вид кандидата
(артист/трек/альбом) как бейдж — 0.3.39.

### API

```
POST   /api/resolve/query      разобрать запрос
POST   /api/resolve/confirm     подтвердить соответствие
POST   /api/resolve/reject      отклонить (уже было: DELETE /aliases + POST /import)
GET    /api/resolve/aliases     что выучено
GET    /api/resolve/misses      где мозг спотыкается
POST   /api/resolve/import      массово из текста
POST   /api/resolve/suggest     спросить ИИ разово
GET    /api/resolve/suggestions предложения ИИ, ждущие решения
POST   /api/resolve/decide      принять/отклонить предложение
```

## 1. Установочный пакет станции (root, без YAM)

- **`package/package-root.py`** — tar.gz под рутированную станцию: бинари под
  архитектуру (ELF-проверка), `install.sh`/`uninstall.sh`, шаблон `config.json`,
  `bus.conf`, README, `manifest.json` (имя→sha256); рядом `.sha256`.
  Суффиксы: armv7 = `<имя>`/`<имя>-armv7`, arm64 = `<имя>-arm64`.
- **`package/root/install.sh`** (на станции, от root): кладёт в `/data/kumaflow`
  (env `KF_ROOT`), `KF_EXPECT_ARCH` сверяет `uname -m`; `config.json` создаёт
  только если его нет — **адрес Navidrome и токен мозга правятся в панели**,
  при установке шаблон пустой. Автозапуск: `kf-station daemon install`.
- **`package/install-root.py`** — установка с ПК одной командой (SSH):
  `--uname` (спросить архитектуру), `--dry-run`, `--uninstall`, `--root-dir`,
  `--expect-arch`; SSH-алиас из `~/.config/alice-cli/ssh.json` или `--host`.
- **Готовые артефакты** (в `dist/` станции и в папке ниже):
  `kf-station-root-0.1.0-yandexmini-armv7.tar.gz` (4.3 MiB) и `…-aarch64.tar.gz`
  (4.0 MiB).
- **Папка для любого ПК: `D:\kf-station-install\`** — самодостаточная:
  `ИНСТРУКЦИЯ.md` (ssh.json → `--uname` → `--dry-run` → установка → панель →
  проверка), `install-root.py` и оба тарбола. Оттуда ставится без проекта.

## 2. Native-плеер без Docker

- **`native/build-native.py`** — полная замена `build-native.sh`:
  компилятор zig (`pip install ziglang`), armhf/arm64-заголовки из Debian
  buster качаются и распаковываются в `native/.sysroot-*` на чистом Python
  (`native/debtool.py`) — .deb это ar+data.tar.xz; `nm -u` заменён своим
  парсером ELF (`native/elf_undef.py`, arm32/arm64).
- Фиксация glibc: таргет `arm-linux-gnueabihf.2.28` → в бинаре максимум
  `GLIBC_2.4` (zig без фиксации тянет `GLIBC_2.34` — старая прошивка не
  заведёт). Готово: `dist/kf-station-player` (armv7, 205 KiB) и
  `…-player-arm64`; NEEDED `libc.so.6 + libglib.so + libquasar_gstreamer.so`,
  как у Docker-сборки; живая проверка — `probe` на станции.

## 3. Треки/альбомы не искались: найдено и починено (0.3.38 → 0.3.39)

- **Причина 2:** получив трек-кандидата, станция искала в Navidrome строку

- **Мозг 0.3.38** (`098a10d`): кандидаты несут `title` (чистое название) и

  запроса против слов названия после транслита; фонетика, субстрок) +

  юрселф» → трек 0.87 (был артист 0.80), «отдыхай» по-прежнему не находит.
  28/28 тестов.
- **Станция:** `kind: "any"`, `TopK 5`, поиск по `c.searchName()` (title);
  `go vet`/`go test` чисто; пересобраны демон и оба root-пакета; пакеты в
  `D:\kf-station-install\packages\` обновлены.
- **Веб-морда** (`685fd9a`): проба «Что поймёт мозг» и «Спросить ИИ» идут с
  `kind: any`, показывают бейдж вида (артист/трек/альбом) и чистое название;
