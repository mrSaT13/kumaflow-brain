## Что сделано в мозге (0.3.35 → 0.3.37)

**Проблема, с которой начали:** голос/ASR пишет «Эминем» кириллицей, в каталоге
«Eminem» — обычный поиск не находит.

- **0.3.35 — спасатель запроса.** `POST /api/resolve/query`: точное совпадение →
  транслитерация → «звуковой» ключ (гласные убраны) → похожесть написания →
  совпадение по слову → выученные алиасы. Плюс внешний кандидат из Яндекс.Музыки.
  Самообучение без тыков: `query_misses` (промахи) + `query_aliases` (память);
  мозг сам разбирает промахи (`auto_learn`) и учится на поведении юзера
  (`learn_from_behavior`). Крон «Самообучение поиска» раз в час.
- **0.3.36 — склейка похожих написаний.** Голос пишет одно слово по-разному
  («имейджен драгонс» / «имайджен драгонс»): ближайшее похожее написание
  алиаса теперь тоже срабатывает.
- **0.3.37 — треки/альбомы + ИИ.** Резолвер по видам `artist|track|album|any`;
  запрос «Eminem Lose Yourself» ищется по паре «название + исполнитель».
  `services/query_ai.py`: модель получает список названий из библиотеки и
  предлагает варианты (id не выдумываются); предложения копятся в
  `ai_suggestions` и ждут решения юзера — «Это оно» (→ алиас) / «Не то».

### Веб-морда

Страница **/resolve** («Умный поиск» в меню «Задачи»): плитки статистики,
таблица выученного (правка/забыть), список промахов (кнопка «Научить»),
форма «Научить слову», проба «Что поймёт мозг», массовый импорт/экспорт
текстом (`слово = как правильно`), раздел **«Предложения ИИ»**.

### API

```
POST   /api/resolve/query      разобрать запрос
POST   /api/resolve/confirm     подтвердить соответствие
POST   /api/resolve/reject      отклонить (уже было: DELETE /aliases + POST /import)
GET    /api/resolve/aliases     что выучено
GET    /api/resolve/misses      где мозг спотыкается
POST   /api/resolve/import      массово из текста
POST   /api/resolve/suggest     спросить ИИ разово
GET    /api/resolve/suggestions предложения ИИ, ждущие решения
POST   /api/resolve/decide      принять/отклонить предложение
```

## Что осталось (нужно от юзера)

1. `sh build-native.sh` (нужен Docker) → `dist/kf-station-player` — последний
   бинарь пакета.
2. `uname -m` на колонке: Мини Плюс (YNDX-00021) — 32-бит, но профиль
   `yandexmini` в карте AliceBridge говорит `arch: aarch64`. Если `armv7l` —
   поправить `package/profiles/yandexmini.yaml` (`arch: armv7`,
   `triple: armv7-unknown-linux-musleabihf`).
3. **Адрес мозга** (HTTPS) — он же, что юзер открывает в браузере; + выпустить
   токен в веб-морде («Мои токены» → пресет «Плеер») и вписать его в панель
   станции («Источники» → Мозг: url/токен/user=mama/device=yandex-station).
4. Деплой мозга на сервере: `cd deploy && git pull && docker compose up -d --build`.
