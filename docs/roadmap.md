## Мои устройства (в работе локально, не пушить до конца перелива)

- [x] **Вкладка «Мои устройства» в своём профиле.** Живые слоты волны +
  переименование в человекочитаемые имена («Десктоп ПК» вместо
  `EF9D7D06-…`), что играет сейчас на каждом (сверка перед переименованием),
  токены пользователя с подсветкой дублей имён. Изоляция конструкцией:
  `/api/me/devices` не принимает user_id — владелец берётся из токена,
  секция рендерится только в своём профиле.
- [x] **Имена в селекторе волны и «Продолжить с …» (веб).** Селектор, строка
  «сейчас» и handoff-метка показывают своё имя (фолбек — сырая метка);
  `_devices_summary` отдаёт `display_name` в уже существующих опросах.
- [ ] **Имена в плеерах.** Телефон/десктоп забирают имя при старте
  (`GET /api/me/devices` по своему токену) и показывают в «Продолжить с …».
- [x] **Прятать админ-кнопки от не-админов.** Сканирование/анализ/тексты/
  кластеры/отмена/очистка — бэк уже отдаёт 403, веб сверяет
  `whoami.is_admin` и не показывает (`useIsAdmin`).

## Волна от сида (как «радио» в ЯМузыке, локально — плеер дёргает API)

- [x] **Радио по артисту.** `POST /api/wave/seed {kind: artist}`: ядро — топ
  артиста, добор — локальные похожие (жанры+кластеры) + серверные
  `getSimilarSongs2`, ранжирует общий скоринг волны. Сид пишется в
  `wave_seeds`, собирается плейлист «Волна по {артист} · {дата}», авто-пуш
  за тумблером. Кнопок в вебе нет — только API для плеера.
- [x] **Радио по треку.** `POST /api/wave/seed {kind: track}`: движок —
  `cold_start(seed_track_id)` (аудио/CLAP-косинус + кластер), сид первым
  номером (энергомостик), серверный добор туда же. Сид/плейлист/пуш — как
  у артиста.
- [ ] **Капсула сида в плеерах.** `GET /api/wave/seed` отдаёт сид
  («волна по Eminem»); плеер рисует капсулу на главной и кнопку радио
  у артиста/трека. `DELETE /seed` — сброс.

## Мозги остальным генерациям

- [x] **Единый скоринг для daily/smart/weekly/discovery.** Все генерации
  отдают свой предфильтрованный пул в `wave.rerank_pool()` — общее ядро
  (CLAP, skip-risk, UCB-руки, auto-mood, коллаборативка, новизна).
  Характер плейлистов задают предикаты пулов (night/sport, forgotten-окно,
  CLAP-recall+MMR у weekly, cold-start recall у daily), порядок внутри —
  ядро. Выдача фиксируется в `rec_feedback` (source daily/smart/weekly).
- [x] **Обученный скип-предиктор.** `services/skip_model.py`: логистическая
  регрессия на PlayEvent (15 признаков, sklearn, numpy-фолбек без него).
  Замена — внутри `_skip_prob()`: модель есть и данных хватает
  (≥5000 размеченных, ≥200 ранних скипов) — её P(skip), иначе эвристика
  `skip_risk()`. Метрики — в `AppSetting['skip_model']`.

## Новые клиенты и ingestion

- [ ] **ESP-колонка как клиент.** Легкий плеер-клиент на ESP32 (Subsonic/Navidrome
  стрим + публикация очереди в `/api/wave/publish` + прием волны):
  кухонно-гаражный эндпоинт экосистемы.
- [x] **«Сонар» — что сейчас играет (без внешних API).** Аудио-фингерпринтинг:
  пики спектрограммы → парные хэши → матчинг гистограммой дельт.
  Плеер присылает запись кнопкой (`POST /api/sonar/recognize`), мозг отвечает
  треком (`track_id` + `external_id`). Включается админом тумблером
  (`automation.sonar_enabled`), отпечатки — чанками (`POST /api/sonar/enroll`).
  Бонусом: дубли по звуку (`GET /duplicates`) и enrich пустых
  genre/year/album из двойника (`POST /enrich`). DSP на чистом numpy.
- [ ] **Умный загрузчик через yt-dlp.** Поиск недостающего (коллаборативка
  посоветовала трек, которого нет в библиотеке) → загрузка → скан →
  sonic-анализ → в волну. С дедупом и лимитами, opt-in.
