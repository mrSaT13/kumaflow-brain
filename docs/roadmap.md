## Волна от сида (как «радио» в ЯМузыке)

- [ ] **Волна по артисту.** Кнопка «радио по артисту»: сид = артист, центроид по его
  трекам + похожие артисты (collab/artist-similarity), diversity по альбомам.
  Тот же скоринг, что у «Моей волны» (CLAP + скип-риск + руки бандита).
- [ ] **Волна по треку.** Кнопка «радио по треку»: сид = один трек, audio- и
  CLAP-косинус + ассоциативный ряд (`session_assoc`), энергетический мостик
  от текущего трека первым номером.

## Новые клиенты и ingestion

- [ ] **ESP-колонка как клиент.** Легкий плеер-клиент на ESP32 (Subsonic/Navidrome
  стрим + публикация очереди в `/api/wave/publish` + прием волны):
  кухонно-гаражный эндпоинт экосистемы.
- [ ] **Локальный Shazam по библиотеке (Dejavu).** Аудио-фингерпринтинг:
  «что сейчас играет?» → маппинг в `Track.external_id`,dedup дублей
  и enrich метаданных без внешних API.
- [ ] **Умный загрузчик через yt-dlp.** Поиск недостающего (коллаборативка
  посоветовала трек, которого нет в библиотеке) → загрузка → скан →
  sonic-анализ → в волну. С дедупом и лимитами, opt-in.
